# 잿빛 왕관 토벌대 — 프로토타입 v0.50

기획서 로드맵 1단계(프로토타입) 범위의 오프라인 솔로 빌드입니다. 설치나 서버 없이 `index.html`을 브라우저(Chrome·Edge 권장)로 열면 바로 실행됩니다.

## v0.50 변경
- 모바일 이동 조이스틱이 누른 곳보다 아래에 그려지던 문제 수정 (조이스틱 위치를 터치 영역 기준 좌표로 계산)

## v0.49 변경
- 공격·특수기술·각성기 아이콘 15종을 캐릭터와 같은 2px 칸 도트 버전으로 교체 (하단 스킬 바, 모바일 터치 버튼 모두)

## v0.48 변경 — 모바일 화면 맞춤 수정
- 세로로 연 뒤 가로로 돌리면 게임 화면이 절반 크기로 남던 문제 수정: 회전·브라우저 바 변화(visualViewport)마다, 그리고 크기가 바뀐 걸 감지하면 즉시 다시 맞춤
- 터치 버튼 크기·위치를 화면 높이에 비례하게 (`--u`). 게임 화면 옆에 여백이 있으면 지도·일시정지·전체화면 버튼을 그 여백에, 없으면 미니맵 아래 줄에 배치 → 점멸 버튼과 겹치지 않음

## v0.47 변경 — 모바일 터치 조작

- 이동: 화면 왼쪽 아래 아무 곳이나 눌러 끌면 그 자리에 가상 조이스틱 (8방향)
- 오른쪽 버튼: 공격(큰 버튼, 누르고 있으면 연사) · 스킬 · 각성 · 점멸 · F(상호작용할 게 있을 때만) · 지도 · 일시정지 · 전체화면(지원 기기만). 스킬·각성 버튼은 직업 아이콘, 쿨타임 중엔 흐려짐
