## v0.73 변경 — 크루가쉬: 깔끔한 경고 · 강력한 타격 · 휘두르는 돌진 · 자기편도 휩쓸림

- **문 봉쇄**: 전투·엘리트·봉인·보스 방에 들어가면 문이 잠김(성채는 쇠창살, 초원은 가시덩굴). 적을 모두 쓰러뜨리면 열림. 문으로 걸어 나가면 짧은 암전 후 다음 방
- **보스 방 봉인**: 엘리트 방 2곳을 처치해야 보스 방 문이 열림. 보스 방 문에는 붉은 문장과 `엘리트 n/2` 표시
- **방 구조물**: 기둥(초원은 나무), 무너진 벽(초원은 덤불), 잔해(초원은 바위), 구덩이(초원은 연못). 13가지 배치를 문 사이가 반드시 이어지게 검사해서 고름

- **보물 상자**: F로 열기. 보물 방은 레어 이상 75%, 비밀 방은 레어 이상 100%(유니크 50·레전더리 15%) + 결정
- **상인**: 체력 물약·장비 꾸러미(레어 이상)는 항상, 투지 구슬·핏빛 영약·철광석 중 2개. 런 골드로 구매 (2스테이지는 1.3배)
